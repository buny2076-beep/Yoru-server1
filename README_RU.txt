# YORU AI Master — серверный стартовый проект

## Что уже работает
- Раздаёт сайт YORU из `public/index.html`.
- Endpoint `POST /api/ai-master/generate` принимает JSON `{ "prompt", "type", "style", "ratio" }`.
- Для `type: "image"` вызывает OpenAI Images API, сохраняет PNG и возвращает URL в формате, который ожидает интерфейс YORU.
- `GET /health` проверяет работу сервера и наличие настроек.

## Важно про видео
По официальной документации OpenAI, прежний Videos API и модели Sora 2 были отключены 24 сентября 2026 года. Поэтому этот проект не притворяется, что видео уже генерируется. Для видео нужно выбрать другого актуального провайдера и написать адаптер именно под его API.

## Запуск локально
Требуется Node.js 20 или новее.

1. Распакуй архив.
2. В терминале в папке проекта выполни `npm install`.
3. Скопируй `.env.example` в `.env`.
4. В `.env` укажи `OPENAI_API_KEY=...`.
5. Выполни `npm start`.
6. Открой `http://localhost:10000`.

## Развёртывание на Render
1. Загрузить папку проекта в собственный GitHub-репозиторий.
2. В Render выбрать **New → Web Service** и подключить репозиторий.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. В Environment добавить `OPENAI_API_KEY` и, при желании, `OPENAI_IMAGE_MODEL`, `OPENAI_IMAGE_QUALITY`.
6. После деплоя открыть выданный Render URL. Сайт и API будут работать на одном домене.

## Подключение интерфейса
Так как HTML и API раздаются с одного домена, в разделе «ИИ мастер» укажи endpoint:
`https://ТВОЙ-ДОМЕН/api/ai-master/generate`

Не добавляй `/` в конце URL, это не требуется.

## Стоимость и лимиты
Генерация не безлимитная: провайдер тарифицирует запросы и применяет лимиты аккаунта. Установи лимиты расходов/usage limits в кабинете провайдера и не публикуй API-ключ. Бесплатный Render также имеет ограничения и может засыпать/останавливаться.

## Хранение
Созданные PNG временно хранятся в `public/generated/`. На бесплатном/эфемерном хостинге файлы могут исчезнуть при перезапуске или новом деплое. Для постоянного хранения подключи object storage.

## Безопасность перед публичным запуском
Добавь аутентификацию, rate limiting, ограничение расходов на пользователя и модерацию запросов. В стартовом шаблоне эти production-меры не реализованы.
